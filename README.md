# mb997d_part
support part for mb997d board

## Advantages
> fast to design<br>
> cheap to print<br>
> portable<br>

## Offsets

mb997d stm32f4-discovery board size dimensions in mm :<br>
> width = 66<br>
> length = 97<br>
> thickness = 1.6<br>
> tolerance = 0.5<br>
